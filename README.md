# MathR5 prototype

Статический лендинг и кликабельная мини-диагностика для проверки гипотез MathR5.

## Что внутри

- `index.html` - лендинг, диагностический блок, пример отчета, форма интереса.
- `styles.css` - адаптивные стили.
- `app.js` - интерактивная мини-диагностика.
- `.nojekyll` - отключает Jekyll на GitHub Pages.

## Публикация на GitHub Pages

1. Создать новый публичный репозиторий, например `mathr5-prototype`.
2. Загрузить содержимое этой папки в корень репозитория.
3. В GitHub открыть `Settings -> Pages`.
4. Включить публикацию из ветки `main`, папка `/root`.
5. Дождаться URL вида `https://<username>.github.io/mathr5-prototype/`.

## Перед трафиком

- Подключить реальную форму сбора контакта или заменить форму ссылкой на Google Form.
- Добавить UTM/source tags в ссылки для трех углов: боль, диагностика, отчет.
- Вручную переносить лиды и события в таблицу проверки гипотез.
